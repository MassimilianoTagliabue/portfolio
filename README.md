# Portfolio — Full Stack Developer

SPA in React + TypeScript (Vite), dark mode con layout ispirato a Bento Grid / Vercel UI.

## Sezioni

- **Hero** — brand, ruolo, CTA
- **Progetti** — card responsive con tag tecnologie
- **Skills** — Frontend, Backend & DB, DevOps
- **Contatti** — GitHub, LinkedIn, email

## Avvio

```bash
npm install
npm run dev
```

Build produzione: `npm run build`
